One ledger, four kinds of node

Cash accounts, gold, a car, a property, a brokerage book and an installment balance are all the same thing: somewhere value sits. Model them as one typed list of nodes, and every event in the app — an exchange, an expense, a gold purchase, an installment payment — becomes the same shape: value leaving one node and arriving at another. That single shape replaces four separate mechanisms in the old app.

Cash node
A bank sub-account
One currency, one purpose. HSBC Egypt · EGP current · EGP. Balance is opening plus every movement.
Asset node
Something you own
Gold in grams, a car, property equity, a brokerage book. Valued live, in its own unit.
Liability node
Something you owe
The unpaid balance of an installment plan. Falls as payments land.
External node
Outside your books
Salary, an expense category, a dealer, a friend. Where value comes from and goes to.

Every event is a transaction with one or more legs

A leg moves value from one node to another. A transaction groups the legs that happened together, so a chain like “convert dollars, then pay the installment” is one entry in the log with two legs — not two unrelated rows you have to mentally join.

The asset node carries its own unit — grams, shares, one car — and its EGP value is derived from the live price, never stored.

What this replaces

Four bespoke mechanisms become one. Gold purchases, the installment array, the order log and the expense list are all movement rows today, each with its own shape, its own date parser and its own arithmetic in accrue().
Net worth becomes one rule. Sum the asset nodes, subtract the liability nodes. No special case for cash, none for gold, none for the car.
The property ring falls out for free. Equity node over equity plus liability — no ph_paid / ph_total pair to keep in step.

What it costs

It is a bigger rebuild. This is no longer a port of the dashboard — it is a different core with the dashboard's behaviour proved on top of it.
Rule zero still binds. Every F-### must still produce the same number. The model has to reproduce the snapshot accrual, not replace it, until Q24 is decided.
Today's figures do survive it. Equity-only and asset-minus-liability give the same net worth: 12,178,087 owned less 11,131,673 owed is the 1,046,414 Palm Hills equity the app already shows.
